# Sprint: P3.1 — Implementation Sprint Zero

## Purpose
Establish product execution infrastructure for SocietyOS.

This sprint is non-feature, non-product, non-user-facing.
It is strictly foundational.

## Scope
- Branch architecture
- CI/CD infrastructure
- Environment separation
- Repo structure scaffold
- Sprint governance
- Execution discipline
- Versioning system
- Migration safety

## Out of Scope
- Feature development
- API expansion
- UI work
- AI model work
- Product functionality
- Domain logic changes

## Rules
- No direct commits to main
- No uncontrolled merges to develop
- No architecture drift
- No destructive refactors
- No mixed-concern PRs
- No feature commits in Sprint Zero

## Exit Criteria
- CI pipelines active
- Governance pipelines active
- Multi-env config live
- Repo scaffold in place
- Sprint governance active
- Versioning model defined
- Execution discipline enforced
